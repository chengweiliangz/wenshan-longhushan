# 3 分钟演示脚本

1. 首页介绍：问山是龙虎山专属的漫游指南，小道士帮助年轻游客把“想去”变成具体的行程草案。
2. 选择 2 天、1000 元、“山水放空 + 道文化探秘”、慢节奏，生成行程。展示实际景点、时间和示例费用。
3. 改成 3 天、200 元，重新生成。指出超预算差额和价格待核验信息。
4. 收藏一份行程，打开“我的漫游”，展示收藏持久化，再下载文本。
5. 点象鼻山或行程节点的耳机图标，查看有 UNESCO 来源的讲解。点“听一听”，测试本机语音。
6. 在“灵感手记”选择地点，输入真实感受，选社交文案或 30 秒分镜，生成、编辑、复制/下载。
7. 打开右上角“API 设置”，展示华东师大 ecnu-plus、三种接口格式、密钥不回显、测试连接与保存。当前已接入真实 AI；停用后仍有本地演示。票务交易、图像识别和 AR 是下一阶段。

演示前运行 `npm run check`，启动服务，打开浏览器。若语音缺少中文声音，讲解仍可文字阅读。不要把示例费用当作真实产品报价。
